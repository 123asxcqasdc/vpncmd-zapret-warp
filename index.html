[ Обход DPI для Windows ]


      

        VpnCMD ставит zapret и Cloudflare WARP одной командой.
        Скачивает свежую сборку, настраивает службу, создаёт нужные списки и показывает
        прогресс загрузки. Запускайте повторно — уже установленное будет пропущено.

## Что внутри

        четыре части одного скрипта
      

      

        

          01
          
Zapret

          
Обход DPI для YouTube и Discord. Скачивается последняя сборка zapret-discord-youtube с GitHub.

          → github.com/Flowseal
        

        

          02
          
WARP OPTIONAL

          
Cloudflare WARP устанавливается только если его ещё нет. Уже установленный клиент не трогается.

          → 1.1.1.1
        

        

          03
          
Служба

          
Регистрирует автозапуск zapret, поднимает WinDivert и создаёт недостающие lists\*-user.txt.

          → автозапуск
        

        

          04
          
Прогресс-бар

          
Загрузка файлов в стиле apt: проценты, скорость, ETA и полоса. Никакого «зависшего» окна.

          → 0 → 100%
        

      

    

  


  

    

      

        
## Как работает

        запуск → установка → готово
      

      

        

          01
          
Проверка прав

          
Скрипт проверяет администратора и при необходимости запрашивает UAC. Дальше всё идёт в одном окне.

        

        

          02
          
Загрузка zapret

          
С GitHub скачивается актуальный архив, распаковывается в zapret_install\ рядом со скриптом.

        

        

          03
          
Настройка службы

          
Устанавливается служба zapret со стратегией general (FAKE TLS AUTO) и автозапуском.

        

        

          04
          
Списки

          
Создаются list-general-user.txt, list-exclude-user.txt и ipset-exclude-user.txt — без них служба падала бы с кодом 1067.

        

        

          05
          
WARP

          
Если Cloudflare WARP не найден — скачивается и ставится MSI. Если найден — шаг пропускается.

        

        

          06
          
Проверка

          
Служба запускается, скрипт проверяет процесс winws и выводит Done.
