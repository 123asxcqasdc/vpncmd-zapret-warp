[ Обход DPI для Windows ]


      
VpnCMD ставит zapret и Cloudflare WARP одной командой.


      

        

          C:\>
          powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://vpn-cmd.p7z.ru/install.ps1 | iex"
          
        

        

          откройте cmd, вставьте команду и подтвердите UAC ·
          исходники на GitHub ↗
        

      

    

  


  

    

      

        
## О проекте

        четыре части одного скрипта
      

      

        

          01
          
Zapret

          
Обход DPI для YouTube и Discord. Скачивается последняя сборка zapret-discord-youtube с GitHub.

          → github.com/Flowseal
        

        

          02
          
WARP OPTIONAL

          
Cloudflare WARP устанавливается только если его ещё нет. Уже установленный клиент не трогается.

          → 1.1.1.1
        

        

          03
          
Служба

          
Регистрирует автозапуск zapret, поднимает WinDivert и создаёт недостающие lists\*-user.txt.

          → автозапуск
        

        

          04
          
Одна команда

          
Не нужно ничего скачивать вручную: команда сама загрузит установщик и запустит его с правами администратора.

          → cmd
        

      

    

  


  

    

      

        
## Установка

        одна команда в cmd
      

      

        

          

            C:\>
            powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://vpn-cmd.p7z.ru/install.ps1 | iex"
            
          

          
    
            
  1. 
              01
              
    Откройте cmd. Нажмите Win+R, введите cmd и нажмите Enter.
    
            
    2. 
            
  2. 
              02
              
    Вставьте команду. Щёлкните правой кнопкой в окне cmd или используйте Ctrl+V, затем Enter.
    
            
    3. 
            
  3. 
              03
              
    Подтвердите UAC. Установщик сохранится в %USERPROFILE%\Downloads\VpnCMD и запустится с правами администратора.
    
            
    4. 
            
  4. 
              04
              
    Дождитесь Done. Повторный запуск безопасен: уже установленное будет пропущено.
    
            
    5.

## Возможности

        без ручной настройки
      

      
    
        
  • ├──Автозапуск — служба zapret поднимается вместе с Windows
    • 
        
  • ├──Идемпотентность — повторный запуск пропускает уже установленное
    • 
        
  • ├──Свежая сборка — zapret скачивается с GitHub при каждом запуске
    • 
        
  • ├──Прогресс — проценты, скорость и ETA вместо тишины в окне
    • 
        
  • ├──WARP — ставится только если ещё не найден в системе
    • 
        
  • ├──Списки — недостающие lists\*-user.txt создаются автоматически
    • 
        
  • ├──Одна команда — не нужно ничего скачивать вручную
    • 
        
  • └──UAC — права администратора запрашиваются самим скриптом
    •
